\# Chord Progression Helper



A beginner-friendly chord progression helper for musicians and worship teams.



\## Features



\- Pick a major key (C, G, D, A, F, Bb, or E) and see its 7 chords

\- Click any chord to see its Roman numeral, quality, position, function, and piano notes

\- See which chord it often moves to, and click to jump there

\- Copy a whole progression as text

\- Save favorite keys, jump back to them, and remove them (saved in your browser)



\## Technologies Used



\- HTML

\- CSS

\- JavaScript (no libraries)



\## How to Run



1\. Download or clone this repository

2\. Open `index.html` in your web browser



\## Future Improvements
